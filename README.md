# LanguageProcessor-PL-Parser-IPCA

Projeto académico desenvolvido na unidade curricular de **Processamento de Linguagens**, focado na implementação de um analisador léxico e sintático em Python, utilizando a biblioteca **PLY (Python Lex-Yacc)**.  
Inclui definição da gramática, construção do lexer e parser, e um conjunto de ficheiros FCA usados para validação e teste.

## Funcionalidades principais

* Implementação de um **lexer** em Python (regras de tokens, padrões e erros).
* Implementação de um **parser** com PLY, baseado numa gramática LR.
* Gestão de erros léxicos e sintáticos.
* Validação de ficheiros em formato **FCA**.
* Geração de árvores sintáticas e mensagens de análise.
* Scripts organizados em módulos: `lexer.py`, `grammar.py` e `main.py`.

# LanguageProcessor-PL-Parser-IPCA

Academic project developed for the **Language Processing** course, focused on implementing a lexical and syntactic analyzer in Python using **PLY (Python Lex-Yacc)**.  
Includes grammar specification, lexer and parser construction, and multiple FCA test files.

## Main Features

* Implementation of a Python **lexer** with token rules, patterns and error handling.
* Construction of a **PLY parser** based on an LR grammar.
* Lexical and syntactic error detection.
* Validation of **FCA** formatted files.
* Generation of parsing output and syntax structures.
* Modular structure with `lexer.py`, `grammar.py`, and `main.py`.
